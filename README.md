# SimpleTetris

외부 의존성 없이 HTML 파일 하나로 동작하는 테트리스. 빌드 도구도, 패키지 설치도, 서버도 필요 없습니다.

가이드라인(SRS 회전, 7-bag 랜덤, 홀드, 락 딜레이, T-스핀·B2B·콤보 점수)을 따라 구현했습니다.

## 플레이

**[hyunsuyu.github.io/SimpleTetris](https://hyunsuyu.github.io/SimpleTetris/)** — 바로 플레이할 수 있습니다.

로컬에서 실행하려면 레포를 받은 뒤 `index.html`을 브라우저로 열면 끝입니다.

```bash
git clone https://github.com/HyunsuYu/SimpleTetris.git
```

Canvas 2D와 `localStorage`만 사용하므로 최신 데스크톱·모바일 브라우저에서 그대로 동작합니다. `file://`로 열어도 되고, 정적 호스팅에 그대로 올려도 됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 좌우 이동 (길게 누르면 자동 반복) |
| `↓` | 소프트 드롭 |
| `Space` | 하드 드롭 |
| `↑` / `X` | 시계 방향 회전 |
| `Z` / `Ctrl` | 반시계 방향 회전 |
| `C` / `Shift` | 홀드 |
| `P` / `Esc` | 일시정지 |
| `R` | 재시작 |

화면 폭이 좁으면(640px 이하) 하단에 터치 버튼 줄이 나타나고, 사이드 패널이 접힙니다.

## 게임 규칙

### 피스 생성과 회전

- **7-bag 랜덤** — I·J·L·O·S·T·Z 7종을 섞어 한 백으로 만들고, 백을 모두 소진하면 다음 백을 이어붙입니다. 같은 피스가 연속으로 몰리거나 오래 안 나오는 일이 없습니다.
- **SRS(Super Rotation System)** — 회전이 막히면 표준 월킥 테이블 순서대로 최대 5개 오프셋을 시도합니다. I 피스는 전용 테이블을 사용하고, O 피스는 킥 없이 제자리 회전합니다.
- **넥스트 5개**를 미리 보여주고, **고스트 피스**로 착지 위치를 표시합니다.

### 홀드

`C`로 현재 피스를 보관하고 보관 중이던 피스와 교체합니다. 한 번 사용하면 그 피스가 착지해 고정될 때까지 다시 쓸 수 없으며, 잠긴 동안 홀드 패널이 흐리게 표시됩니다.

### 락 딜레이

피스가 바닥에 닿아도 **500ms** 동안은 고정되지 않습니다. 그 사이에 이동하거나 회전하면 타이머가 초기화되지만, 리셋은 피스당 **최대 15회**까지만 허용됩니다. 무한정 버티는 것을 막으면서도 마지막 순간의 미세 조정은 가능합니다.

### 낙하 속도

10줄을 지울 때마다 레벨이 1 오릅니다. 한 칸 낙하에 걸리는 시간은 표준 곡선을 따릅니다.

```
낙하 간격(ms) = (0.8 - (레벨 - 1) × 0.007) ^ (레벨 - 1) × 1000
```

레벨 1에서 1000ms, 레벨 5에서 약 355ms, 레벨 10에서 약 64ms이고, 레벨 13부터는 하한인 20ms로 고정됩니다. 레벨 계산에 쓰이는 값은 20에서 상한 처리됩니다.

## 점수 체계

줄을 지운 점수에는 **현재 레벨이 곱해집니다**. 드롭 점수는 레벨과 무관합니다.

| 액션 | 기본 점수 |
| --- | --- |
| 싱글 / 더블 / 트리플 | 100 / 300 / 500 |
| 테트리스 (4줄) | 800 |
| T-스핀 싱글 / 더블 / 트리플 | 800 / 1200 / 1600 |
| T-스핀 미니 싱글 / 더블 | 200 / 400 |
| T-스핀 (줄 안 지움) | 400 (미니 100) |
| 소프트 드롭 | 1 / 칸 |
| 하드 드롭 | 2 / 칸 |

**보너스**

- **Back-to-Back ×1.5** — 테트리스나 T-스핀을 연달아 성공하면 1.5배. 사이에 일반 줄 지우기가 끼면 끊깁니다.
- **콤보 +50 × 콤보 수** — 연속으로 줄을 지울 때마다 누적되며, 두 번째 연속부터 점수가 붙습니다(2연속 +50, 3연속 +100…). 줄을 못 지우면 초기화됩니다.

**T-스핀 판정**은 3-코너 룰을 씁니다. 마지막 동작이 회전이고, T 피스 중심을 둘러싼 네 모서리 중 3개 이상이 막혀 있으면 T-스핀입니다. 이때 T가 향한 쪽 두 모서리가 모두 막혀 있거나 마지막 월킥이 최종 오프셋이었으면 정규 T-스핀, 아니면 미니로 처리합니다.

최고 점수는 `localStorage`(`tetris.best`)에 저장되어 다음 방문에도 유지됩니다.

## 입력 처리

| 항목 | 값 | 설명 |
| --- | --- | --- |
| DAS | 150ms | 좌우 키를 누른 뒤 자동 반복이 시작되기까지의 지연 |
| ARR | 40ms | 자동 반복 중 한 칸 이동 간격 |
| 소프트 드롭 반복 | 45ms | `↓`를 누르고 있을 때 한 칸 낙하 간격 |

하드 드롭은 키를 누른 즉시 착지·고정되며, 프레임을 기다리지 않습니다.

## 구조

전체가 `index.html` 한 파일이고, 스크립트는 전역을 오염시키지 않도록 IIFE로 감싸져 있습니다.

- **보드** — 10 × 20, 셀 30px (캔버스 300 × 600). 스폰 위치는 보드 위쪽 음수 좌표에서 시작합니다.
- **렌더링** — 메인 보드, 넥스트, 홀드 각각 별도 캔버스. 블록은 그라디언트와 하이라이트를 얹어 그리고, 고스트는 같은 색 외곽선을 28% 투명도로 그립니다.
- **루프** — `requestAnimationFrame` 기반. 프레임마다 델타 타임을 누적해 중력·락 딜레이·DAS를 갱신하므로 모니터 주사율에 관계없이 동일한 속도로 동작합니다.
- **상태** — `ready` / `playing` / `paused` / `over` 네 가지. 오버레이 한 개를 상태에 맞게 재사용합니다.
