# SimpleTetris

의존성 없는 단일 HTML 파일로 만든 테트리스. [`tetris.html`](tetris.html)을 브라우저로 열면 바로 실행됩니다.

## 기능

- **SRS 회전** — 표준 월킥 테이블 (I 피스 전용 테이블 포함)
- **7-bag 랜덤** — 7종이 한 번씩 나온 뒤 다음 백으로
- **홀드** — 피스가 착지할 때까지 1회 제한
- **고스트 피스**와 **넥스트 5개** 미리보기
- **락 딜레이** 500ms, 이동·회전 시 최대 15회 리셋
- **점수** — 싱글/더블/트리플/테트리스, T-스핀(미니 구분), Back-to-Back 1.5배, 콤보 보너스, 소프트드롭 1점·하드드롭 2점/칸
- **레벨** — 10줄마다 상승, 표준 낙하 속도 곡선
- 최고 점수 `localStorage` 저장, DAS/ARR 좌우 자동반복, 모바일 터치 버튼

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 이동 |
| `↓` | 소프트 드롭 |
| `Space` | 하드 드롭 |
| `↑` / `X` | 우회전 |
| `Z` | 좌회전 |
| `C` | 홀드 |
| `P` | 일시정지 |
| `R` | 재시작 |
